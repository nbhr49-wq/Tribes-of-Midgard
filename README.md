# Tribes of Midgard — 古き記録

GitHub Pages 用の小さなプレイ記録サイトです。

## 構成

- `index.html` — ページ本体
- `style.css` — 森・石板・暗転・動画画面のデザイン
- `script.js` — 石板→記録→暗転→YouTube再生の演出

現在の動画IDは `tNP8YYhGLWg` です。

## GitHub Pagesへの公開

1. GitHubで新しいリポジトリを作成
2. この3ファイルをリポジトリのトップにアップロード
3. Settings → Pages
4. Sourceを `Deploy from a branch`
5. Branchを `main` / `/(root)` にして保存
6. 数分待って公開URLを開く

GitHub PagesはHTML/CSS/JavaScriptの静的サイトを公開できます。
