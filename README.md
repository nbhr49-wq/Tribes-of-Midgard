# Tribes of Midgard — 古の記録 V4

V4は、ユーザー提供の高解像度2枚目画像を背景として使用します。

## ファイル
- `01-forest.jpg` — 1枚目
- `02-tablet.png` — 新しい高解像度2枚目
- `index.html`
- `style.css`

## 動作
1. 1枚目の「石板に触れる」をクリック
2. 2枚目へ暗転遷移
3. 石板からHTMLテキストが一行ずつ浮かび上がる
4. 最後に「記録映像を見る」が出現
5. クリックすると暗転してYouTube動画を再生
