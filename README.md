V7はV6の演出を維持したまま、2枚目の石板上の文章を読みやすくした版です。

## V7の変更点

- 画像は変更していません
- 文章の背後に、中央だけ薄く暗くなる楕円形の「霞」を追加
- 文字に薄い黒い縁取りを追加
- 金色の発光を少し強調
- 「記録映像を見る」ボタンのコントラストも少し調整

黒い四角形を置くのではなく、石板の質感が見えるように
中央付近だけ自然に暗くしています。
