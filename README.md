## GitHub Pagesへの公開

1. このフォルダの中身をGitHubリポジトリのルートにアップロード
2. GitHubの `Settings`
3. `Pages`
4. `Deploy from a branch`
5. `main` / `/(root)` を選択
6. Save

`index.html` がトップページになります。
